# ICST_Ambi_Reaper v1.0.0

## Deutsch

Erste öffentliche Version des portablen REAPER-Ordners für ICST Ambisonics und den Animator Choreographer.

**Enthalten**
- Toolbar *ICST_Ambi_Automation*: B-Format Player, Encoder 64, Encoder, Decoder, Binaural, HOA Reverb, HOA FX/Master, AmbiGran 16, Auto-Route, Quick Start, Info (öffnet die Online-Doku)
- Skripte unter `Scripts/ICST/Ambi`, Motion-Map-GUI und Spat Motion Automation (OSC)
- Vorkonfigurierter Ordner mit VST3-Plug-ins (ICST, IEM), SWS, js_ReaScriptAPI und ReaPack (macOS)
- Animator Choreographer (Button 13)
- Dokumentation: https://ambisonics.ch/icst-ambisonics-plugins/19_icst_ambi_reaper/docs/

**Downloads**
- `ICST_Ambi_Reaper_1.0.0_macOS.pkg`: Installer nach `/Applications/ICST_Ambi_Reaper` (macOS 12+, Apple Silicon empfohlen)
- `ICST_Ambi_Reaper_1.0.0_scripts-only.zip`: nur Skripte, Toolbar und Doku (für Windows-Aufbau)

**Hinweise**
- Windows: Beta, nicht getestet (Aufbau aus Teilen, siehe README)
- Getestet mit REAPER 7.85 auf macOS
- AmbiGran 16 nur Apple Silicon
- ICST-Teile: GPL-3.0-or-later; Drittkomponenten siehe `THIRD_PARTY_LICENSES.md`

## English

First public release of the portable REAPER folder for ICST Ambisonics and the Animator Choreographer.

**Included**
- Toolbar *ICST_Ambi_Automation*: B-Format Player, Encoder 64, Encoder, Decoder, Binaural, HOA Reverb, HOA FX/Master, AmbiGran 16, Auto-Route, Quick Start, Info (opens the online docs)
- Scripts in `Scripts/ICST/Ambi`, Motion Map GUI and Spat Motion Automation (OSC)
- Preconfigured folder with VST3 plug-ins (ICST, IEM), SWS, js_ReaScriptAPI and ReaPack (macOS)
- Animator Choreographer (button 13)
- Documentation: https://ambisonics.ch/icst-ambisonics-plugins/19_icst_ambi_reaper/docs/

**Downloads**
- `ICST_Ambi_Reaper_1.0.0_macOS.pkg`: installer to `/Applications/ICST_Ambi_Reaper` (macOS 12+, Apple Silicon recommended)
- `ICST_Ambi_Reaper_1.0.0_scripts-only.zip`: scripts, toolbar and docs only (for building on Windows)

**Notes**
- Windows: beta, untested (assembled from parts, see README)
- Tested with REAPER 7.85 on macOS
- AmbiGran 16 is Apple Silicon only
- ICST parts: GPL-3.0-or-later; third-party components see `THIRD_PARTY_LICENSES.md`
